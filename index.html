欢迎回到游戏室

导入你已有的 .nes 文件，点击卡带开始游戏。支持批量导入和拖放，重复文件会自动跳过。

玩家 1：W / S / A / D 对应上 / 下 / 左 / 右；K / J / I / U 对应 A / B / C / D；Enter 开始，右 Shift 选择。
玩家 2：方向键移动，G / F / H / Y 对应 A / B / C / D；T 开始，R 选择。
C = A 连发，D = B 连发，按住即可连续触发。

支持标准 USB / 蓝牙手柄，前两个手柄分别控制玩家 1 / 2。手柄底部 / 右侧 / 左侧 / 顶部四个动作按钮对应 A / B / C / D，Start / Back 对应开始 / 选择。触屏可使用操作面板。

每次新建存档都会保存独立进度，默认用“游戏名称 + 日期时间”命名。支持改名、删除后撤销，拖动左侧手柄或使用 ↑ / ↓ 排序，也可按最新 / 最早排序；导出 JSON 可备份或迁移存档。清除浏览器网站数据会清除卡带和存档，请提前备份。

部分特殊芯片、盗版合卡或修改版 ROM 可能不兼容。页面失焦会自动暂停。
