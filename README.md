# 老霸王 · 时光游戏室

本地 Web NES 模拟器，使用 JSNES 2.1.0，并扩展 Mapper 74（Waixing MMC3）支持。没有远程服务，游戏文件和存档通过 IndexedDB 保存在浏览器中，不上传文件。

## 在线使用

https://MrLiu163.github.io/Web-NES-Emulator/

推送到 `main` 后，GitHub Actions 会自动测试、构建并部署到 GitHub Pages。游戏和存档仍保存在访问者自己的浏览器中。在线站点与本地开发地址的游戏库独立。

## 启动

首次运行 `npm install`，然后：

```sh
npm run dev
```

打开终端显示的地址，默认 http://127.0.0.1:5173/ 。需要在终端保持服务运行。再次启动仍使用同一地址、同一浏览器，才会访问原游戏库。

```sh
npm run build
npm run preview
npm test
```

preview 使用不同端口，因此游戏库与 dev 分开。

## 使用

- 点击“导入游戏”批量选择 `.nes`，或拖入文件。通过 SHA-256 去重；校验文件头、常规 iNES 文件完整性及模拟核心支持情况。上限 32 MB，覆盖几十 KB 至 2 MB 左右的文件。
- 点击游戏卡带开始，点击卡带右侧 × 删除游戏及其存档；删除前需确认。
- 每个游戏支持多个独立存档，点击“新建存档”保存当前进度，默认以“游戏名称 + 日期时间”（北京时间）命名。旧存档自动按此格式显示并保留原进度。支持内联重命名、删除后撤销、拖动左侧 ⠿ 排序、↑ / ↓ 上下移动，以及最新 / 最早优先排序；顺序会保存在本地。导出 JSON 可备份或迁移；导入存档必须与 ROM 的 SHA-256 完全一致。
- 未保存的进度不会自动保留。刷新页面、重启游戏或删除游戏前先保存。清除网站数据会清除卡带和存档。
- 键盘、双人、标准 Gamepad API 手柄与屏幕触控；音量、全屏、CRT 扫描线；切换窗口自动暂停。

| 按键 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 上 / 下 / 左 / 右 | W / S / A / D | 方向键 |
| A / B | K / J | G / F |
| C / D（A 连发 / B 连发） | I / U | H / Y |
| START | Enter | T |
| SELECT | 右 Shift | R |

手柄：标准映射的第 1、2 个手柄对应玩家 1、2；左摇杆 / 十字键移动，底部 / 右侧 / 左侧 / 顶部按钮对应 A / B / C / D（C = A 连发，D = B 连发），Start / Back 对应 START / SELECT。不同设备的映射可能不同。

## 兼容性与验证

ROM 的文件大小不能决定兼容性，主要取决于 Mapper（卡带芯片）、ROM 格式及修改内容。不支持的 Mapper 会在导入时显示原因。超级玛丽、魂斗罗、松鼠大战等需要用你的实际 ROM 测试；并未随项目提供商业游戏。

存档依赖模拟核心对该 Mapper 的状态序列化支持，特殊芯片的存档可能不能完整恢复。请保留备份。当前不支持 ZIP、FDS 或 SNES 格式。

`npm test` 使用原创的最小 NROM 程序验证执行、画面回调、双人按钮、JSON 存档往返、错误 ROM 及不支持的 Mapper。浏览器已验证导入、播放、保存、读取、刷新持久化；尚未验证用户的商业游戏 ROM、实际 USB / 蓝牙手柄及触屏设备。

源码：`src/main.js`（模拟器、持久化、输入及存档），`src/style.css`（响应式界面）。

Mapper 74 扩展位于 `src/nes-core.js`，按照 NESdev 的银行 8 / 9 映射 2 KiB CHR RAM 规则实现，保留完整 ROM 银行编号，并支持 RAM 存档及多地址别名写入。自动化测试验证银行切换、写保护、高银行、CHR 反转、存档恢复及帧执行；尚未验证用户的《重装机兵》ROM。

8×16 人物图块修复位于 `src/ppu-fixes.js`（基于 JSNES PPU，许可证见 `src/jsnes-LICENSE`）：奇数编号的最低位仅选择图形表，不应导致顶半图块错位；精灵零碰撞检测按完整 16 行进行垂直翻转。回归测试覆盖偶数 / 奇数图块、两张图形表、翻转、全部 16 行及重置。已用用户提供的 Mapper 2《西游记》ROM 复现修复前人物错位，并对比修复后游戏画面，同时验证存档恢复后继续执行。

Mapper 25 的 VRC4b / VRC4d 兼容实现位于 `src/mapper25.js`，支持两组地址接线、PRG 切换、八个 1 KiB CHR 银行、镜像和 CPU 周期驱动的 IRQ（包括扫描线分频模式），以及芯片状态存取。参考 NESdev 的 VRC2_and_VRC4 和 VRC_IRQ。已用用户提供的《忍者神龟1》ROM 验证启动、角色选择、关卡画面及存档恢复；尚未进行完整通关测试。

Mapper 15 支持位于 `src/mapper15.js`，包括 32 / 16 / 8 KiB 四种 PRG 模式、镜像、8 KiB 工作 RAM 与存档。为兼容《爆笑三国》等 Mapper 改版 ROM，各模式均保留 CHR RAM 可写；这与原始 K-1029 合卡部分模式的硬件写保护不同（参考 NESdev INES_Mapper_015 的 mapper hacks 说明）。已用用户提供的 ROM 验证启动和难易度选择，以及存档恢复后继续运行；未做完整通关验证。
